# scandalous 2.5.0

## Listing now shows "about" for hour-plus timestamps

`time_ago` opts into `humane`'s new `approximate: true` option (`humane` `v0.4.0`):
timestamps an hour or older now render as `"about 15 hours ago"`, `"about 1 day
ago"`, etc., instead of an exact-looking count. Anything under an hour
(`"3 minutes ago"`, `"less than a minute ago"`) is unchanged.

This listing is a static, server-rendered page with no way to refresh itself once
loaded -- exact hour/day counts overstate their own precision the moment the page
sits open for a while. `approximate` exists specifically for that case; see
`humane-ruby`'s own `docs/releases/v0.4.0.md`.

## Upgrading

`Gemfile` pin tightened to `"~> 0.4.0"` (was `"~> 0.3"`) -- the two-segment form
(`"~> 0.3"`) actually permitted any `0.x` release silently (`>= 0.3, < 1.0`, not
`< 0.4` as the earlier pin bump intended), so this also fixes that: future `0.x`
bumps now need a deliberate `Gemfile` edit instead of arriving unreviewed on a bare
`bundle update`. Run `bundle install` to pick up `humane 0.4.0`.

No other user-facing changes.
