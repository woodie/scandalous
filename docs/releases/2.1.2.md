# scandalous 2.1.2

## Bug fix: file sizes now match Finder

`number_to_human_size` is 1024-based under a "KB" label (Rails' own documented example: `number_to_human_size(1234) => "1.21 KB"`), which doesn't match Finder (1000-based, same label) — confirmed against a real file's Finder size, and the identical bug lambada-web (the Go port of this app) had. Rails dropped the `:prefix` option that used to allow 1000-based output back in Rails 5, so rather than monkey-patch a private Rails class, file sizes are now formatted by a small hand-rolled `human_size` helper, using the same rounding approach lambada's port uses. File sizes on the listing page now match what Finder and zouk report for the same file.

## Delete confirmation now rendered server-side

The confirmation message shown before deleting a scan (previously assembled client-side in JavaScript) is now rendered fully server-side and covered by a spec.

No other user-facing changes — this release also catches up several unreleased commits sitting on `main` since 2.1.0 (test coverage, linting, template cleanup) that didn't warrant their own tag at the time.
