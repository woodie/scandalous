# scandalous 2.4.0

## Developer tooling: JS linting and testing

`public/script.js` (the delete-confirmation script, now its own file
rather than inline in `views/listing.erb`) has real linting and testing
for the first time: [`standard`](https://standardjs.com) (matching
`standardrb`'s zero-config philosophy, and script.js's existing style) and
[`vitest`](https://vitest.dev), with a `context = describe` alias so specs
read like the RSpec `describe`/`context`/`it` hierarchy used elsewhere in
this account.

## CI now also runs standardrb and the JS suite

`.github/workflows/ci.yml` gained a lint step in the `ruby` job
(`bundle exec standardrb` -- the gem was already in the Gemfile but never
actually run) and a new `javascript` job.

## npm scripts for the whole dev loop

`lint-js`/`test-js`/`lint-rb`/`test-rb` cover each half individually;
`npm run check` runs all four in sequence and stops at the first failure,
using compact output (`vitest --reporter=dot`, plain `rspec`) so it stays
readable. See `docs/DEVELOPMENT.md`'s "Linting and testing" section for
the full rundown.

No other user-facing changes.
