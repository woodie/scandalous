# scandalous 2.2.0

## Now using the `humane` gem for file sizes and relative dates

`human_size` and Rails' `DateHelper#time_ago_in_words` are replaced by [`humane`](https://github.com/woodie/humane-ruby), a small formatter library extracted from this app and its Go counterpart, `lambada`. Output for file sizes is unchanged. Relative-time wording changes slightly: no more "about" prefix on the hour bucket (`15 hours ago`, not `about 15 hours ago`), matching Finder and the zouk app.

## Bug fix: future file times were mislabeled "ago"

A freshly-copied file with a timestamp in the future (e.g. from a clock skew) always displayed as "X ago" rather than "X from now" — `time_ago_in_words` wasn't being called in a way that could report future distances correctly. `humane`'s `TimeFormatter` handles this natively.

## Dependency cleanup

`actionview` (and the `activesupport` it pulled in for the test suite's `3.minutes`/`15.hours` sugar) is no longer a dependency — nothing else in the app used it.

No other user-facing changes.
